# Report Template

Single source of truth for the Google Doc body. `prompts_engineering/subagents/ivy.md`
points here rather than carrying a second copy.

Substitutions in `{braces}`. Verbatim transcript text is shown in "quotes" so a
reader can tell what was said from what was derived.

---

```
# {meeting_metadata.title} — Report {meeting_metadata.date}

Attendees: {meeting_metadata.attendees[].display_name, comma-separated}
Duration: {meeting_metadata.duration_minutes} min
Started: {meeting_metadata.started_at}

## 1. Executive Summary

{3–5 sentences. Facts only. What was discussed, what was decided, what happens
next. No opinion, no assessment of tone or productivity.}

## 2. Key Discussion Points

- **{topic.title}** — {topic.summary}

## 3. Decisions Made

- {decision.statement}

## 4. Action Items

| # | Task | Owner (as spoken) | Priority signal | Deadline | Source |
|---|---|---|---|---|---|
| 1 | {task} | "{owner_claim}" / Unassigned | "{priority_signal}" / — | "{deadline_claim}" / — | {source_segment_ids} |

Owner and priority columns are quoted as spoken. Assignment is confirmed against
the attendee list before any ticket is created; Jira priority is set downstream.

## 5. Open Questions & Blockers

**Open questions**
- {question}  *(raised by "{raised_by_claim}")*

**Blockers**
- {description}

## 6. Next Meeting

{next_meeting_claim} / TBD

---
_Generated by Layla AI | {timestamp}_
```

## Section rules

| Section | Rule |
|---|---|
| Header | from `meeting_metadata` only — never scraped from transcript text |
| 1 | 3–5 sentences; omit rather than pad if the meeting was short |
| 2 | one bullet per topic, grouped by theme, not chronological |
| 3 | settled outcomes only; a proposal is a topic, not a decision |
| 4 | one row per item, in the order extracted; never re-rank |
| 5 | empty subsections are stated as "None recorded", not deleted |
| 6 | `TBD` when nothing was said — never inferred from cadence |

## Empty sections

Keep every heading. A report missing section 3 reads as an oversight; a report
whose section 3 says "None recorded" is a finding. Sections 2–6 may each be
"None recorded"; section 1 and the header may not.
